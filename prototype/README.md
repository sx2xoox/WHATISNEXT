# 잔상 아레나 프로토타입 v0.1

기획서 [docs/04-afterimage-arena.md](../docs/04-afterimage-arena.md)의 MVP 범위를 TypeScript + Three.js로 구현한 웹 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

- 브라우저에서 표시되는 주소를 엽니다.
- 주소 뒤에 `?demo`를 붙이면 봇 4명이 플레이하는 관전 모드로 바로 시작합니다.

## 조작

| | 이동 | 대시 (무적) | 밀치기 |
|---|---|---|---|
| P1 | W A S D | F / Space | G |
| P2 | 방향키 | / | . |
| 패드 | 스틱 / 십자키 | A | X |

- 1~2인: P1, P2가 키보드와 패드 1, 2번을 모두 씁니다.
- 3~4인: P1, P2는 키보드, P3, P4는 패드 1, 2번을 씁니다.
- 빈자리는 봇이 채웁니다 (타이틀에서 B로 끄고 켬).

## 규칙 (v0.1)

- 1세트 7라운드, 라운드당 20초
- 코인 +1, 라운드 끝까지 생존 +1. 라운드 중간에 코인 4개가 추가로 나옵니다.
- 최근 3라운드 동안 모든 플레이어가 움직인 궤적이 유령으로 재생됩니다. 닿으면 탈락하고, 내 유령도 위험합니다.
- 라운드마다 카드 1장을 고릅니다. 기획서와 달리 순서대로 고르지 않고 모두 동시에 고르며, 꼴찌는 후보가 4장입니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/game.ts` | 게임 규칙, 유령 기록·재생, 봇 AI. DOM과 Three.js에 의존하지 않음 |
| `src/view.ts` | Three.js 렌더링. 캐릭터는 모델 파일 없이 기본 도형으로 만들고, 유령은 셰이더로 표현 |
| `src/hud.ts` | 점수, 타이머, 타이틀·카드 선택·결과 화면 |
| `src/input.ts` | 키보드, 게임패드 입력 |
| `src/cards.ts` | 능력 카드 5종 |
| `src/config.ts` | 밸런스 수치 |
| `scripts/sim.ts` | 봇 4명으로 여러 세트를 돌려 라운드별 생존율을 출력하는 밸런스 점검 스크립트 |

밸런스 점검 실행:

```bash
npx esbuild scripts/sim.ts --bundle --platform=node --outfile=/tmp/sim.mjs && node /tmp/sim.mjs 40
```
