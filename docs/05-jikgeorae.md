# 직거래 (가제) — 기획서와 프로토타입 v0.1 결정 사항

> 원 기획서(경제 전략 + 블러핑 파티 게임, 4~8인, 20~30분, 순자산 1위 승리)를 바탕으로 프로토타입을 만들면서 정한 규칙을 정리합니다. 수치는 모두 `jikgeorae/src/core/config.ts` 한 곳에서 관리합니다.

## 1. 한 줄 소개

중고 매물을 비공개 경매로 사고, 친구와 흥정·블러핑하며 되팔아, 5라운드 뒤 순자산 1위를 노리는 1인칭 토론장 경제 게임.

## 2. 화면 구성

- **1인칭 토론장**: 플레이어마다 단상이 있고, 가운데 경매대를 사이에 두고 서로 마주 봅니다. 맞은편 벽 전광판에 라운드, 단계, 남은 시간이 표시됩니다.
- **단상 위 물건**: 각자 가진 물건이 단상 위에 3D 모형으로 놓입니다. 누가 어느 시리즈를 모으는지 눈으로 보입니다.
- **말풍선**: 상대가 제안하거나 수락·거절할 때 말풍선으로 말합니다. 온라인에서는 빠른 대화 버튼(“사기 아니죠?”, “보증 붙여주세요” 등)과 거래 제안에 붙인 한마디가 말풍선으로 뜹니다. 실제 대화는 디스코드 같은 음성 채팅을 함께 쓰는 것을 전제로 합니다.
- 캐릭터와 물건은 모델 파일 없이 기본 도형으로 만들었습니다.

## 3. 한 라운드

| 단계 | 시간 | 하는 일 |
|---|---|---|
| 시장 공개 | 20초 | 새 매물 4개 공개. 감정 가능. 이번 라운드 이벤트 적용 |
| 비공개 경매 | 30초 | 매물마다 입찰액을 적어 냄. 입찰 합계는 보유 현금 이하 |
| 직거래 | 80초 | 현금·물건을 섞어 제안, 수락·거절·역제안 |
| 감정 · 정산 | 12초 | 내 물건의 실제 상태 공개, 보증 위반 배상, 이자, 시세 갱신, 다음 이벤트 예고 |

- 모두 **준비 완료**를 누르면 남은 시간과 상관없이 다음 단계로 넘어갑니다.
- 5라운드 후 최종 순자산으로 순위를 매깁니다.

## 4. 원 기획에서 바꾸거나 구체화한 것

### 4.1 보증권 (사기 판정 문제)

원 기획의 "명백한 사기가 확인되면 제재"는 판매자가 시스템 안에서 상태를 주장하는 수단이 없어 판정할 근거가 없었습니다. 그래서 **보증**을 넣었습니다.

- 거래 제안에서 내가 주는 물건에 **보증**을 붙일 수 있습니다. 보증한 물건이 정산 때 하자·고장·가품으로 드러나면, 판매자가 **손실분 + 시세의 30%**를 구매자에게 물어주고 **위반 기록이 공개**됩니다.
- 보증이 없는 거래에서 하는 말은 자유입니다. "상태 좋아요"가 거짓이어도 제재는 없습니다.

"그럼 보증 못 붙이면 사기네 하고 몰아가면 끝 아니냐"는 문제는 이렇게 막습니다.

| 장치 | 효과 |
|---|---|
| 보증권은 한 판에 2장 | 대부분의 거래는 보증 없이 할 수밖에 없음. 보증이 없다는 것이 사기의 증거가 아님 |
| 판매자도 상태를 모를 수 있음 | 감정하지 않은 물건에 보증을 붙이면 판매자도 위험을 짐. "몰라서 보증 못 해요"가 정직한 대답 |
| 보증권 잔량은 본인만 앎 | "보증권 다 썼어요"라는 말도 거짓말일 수 있음 |

### 4.2 감정

- **언제**: 시장 공개, 경매, 직거래 단계 언제든.
- **무엇을**: 내 물건, 경매 매물, 그리고 **나와 관련된 대기 중 제안에 들어 있는 물건**. 거래 제안을 받으면 수락 전에 그 물건을 감정할 수 있습니다.
- **비용**: 10,000원. 가품 주의보 때는 반값.
- **감정서 공개**: 감정한 물건은 감정서를 공개해 모두에게 실제 상태를 보여줄 수 있습니다. 정직하게 비싸게 팔고 싶은 사람의 도구입니다.
- **정산 때 자동 공개**: 정산 단계에서 모든 주인은 자기 물건의 실제 상태를 알게 됩니다. 그래서 "하자인 걸 알고도 파는" 사기가 다음 라운드부터 가능해집니다.

### 4.3 세트 보너스 (거래할 이유)

모든 물건이 같은 시세로 평가되면 직거래는 제로섬이라 합리적인 플레이어는 거래를 피합니다. 그래서 **같은 물건이 사람마다 가치가 다르도록** 세트 보너스를 최종 점수에 넣었습니다.

- 시리즈 5개 × 물건 4종 = 20종.
- 같은 시리즈의 **서로 다른 진품** 2종 +20%, 3종 +60%, 4종 +100% (그 물건들의 평가액 기준).
- 최종 자산 = 현금 + 물건 평가액 + **세트 보너스** + 목표 보너스.

### 4.4 시세 조작 방지

직거래 가격을 시세에 반영하면 친구 둘이 같은 물건을 비싸게 주고받아 시세를 띄울 수 있습니다. 그래서 시세는 **경매 결과(낙찰가, 입찰자 수, 유찰), 매입처 매각량, 이벤트, 작은 무작위 변동**으로만 계산합니다. 라운드당 변동은 ±25%, 마지막 라운드는 ±10%로 제한합니다.

### 4.5 그 밖의 규칙

| 항목 | 결정 |
|---|---|
| 경매 동점 | 현재 순자산이 낮은 사람이 낙찰 (역전 장치). 먼저 낸 사람 우선은 네트워크 지연에 좌우되어 제외 |
| 입찰 잠금 | 모든 매물 입찰액 합계 ≤ 보유 현금 |
| 직거래 수수료 | 현금을 받는 쪽이 5% |
| 제안 만료 | 20초. 한 사람당 대기 중 제안 최대 3개 |
| 역제안 | 받은 제안을 바탕으로 조건을 고쳐 되돌려 보냄. 원래 제안은 거절 처리 |
| 즉시 매각 | 상태를 아는 내 물건만. 시세 × 70% × 실제 상태 |
| 이자 | 정산 때 현금의 5%, 최대 20,000원 |
| 최종 평가 | 마지막 시세 70% + 직전 시세 30%, 실제 상태 반영 |
| 비밀 목표 | 수집가(특정 시리즈 3종), 협상가(서로 다른 3명과 거래), 회전율(거래 4회) |
| 이벤트 | 신제품 출시(전자기기 시리즈 -25%), 수집가 유행(수집품 시리즈 +30%), 가품 주의보(새 매물 가품 25%, 감정비 반값). 한 라운드 전에 예고 |

### 4.6 공개 정보와 비공개 정보

| 공개 | 나만 앎 |
|---|---|
| 각자 가진 물건 종류 (단상 위) | 다른 사람의 현금 |
| 경매 낙찰자와 낙찰가 | 다른 사람의 입찰액 |
| 직거래 성사 기록 (누가 누구와 어떤 물건, 보증 개수). 가격은 비공개 | 직거래 가격 |
| 보증 위반 횟수 | 내 감정 결과, 비밀 목표, 보증권 잔량 |

## 5. 서버 권한 구조

- 게임 규칙(`jikgeorae/src/core/`)은 화면과 분리된 순수 TypeScript입니다. 모든 변경은 `dispatch(명령)`과 `tick(시간)`으로만 일어납니다. 지금은 브라우저에서 돌지만 그대로 Node 서버로 옮길 수 있습니다.
- 클라이언트(사람과 NPC 모두)는 `viewFor(플레이어)`로 **자기가 볼 수 있는 정보만** 받습니다.
- 모든 명령에는 `cmdId`가 붙고, 같은 `cmdId`가 다시 오면 처음 결과를 그대로 돌려줍니다 (중복 요청 방지).
- 거래는 수락 순간 모든 조건을 다시 검증한 뒤 한 번에 실행합니다. 실행 중에는 실패할 단계가 없습니다. 같은 물건이 다른 거래로 넘어가면 그 물건을 쓰는 대기 중 제안은 자동으로 실패 처리됩니다.

## 7. 테스트

- `npm test`: 엔진 14개 — 경매(최고가, 잠금, 동점, 실패한 수정), 직거래(원자적 교환과 수수료, 중복 요청, 이중 판매, 수락 시점 현금 부족, 만료, 보증권 부족), 보증 배상, 정산 공개, 세트 보너스, 전체 진행.
- 서버 6개 — 방 생성·참가, 없는 방·가득 찬 방, 방장만 시작, 다른 사람 현금이 전송되지 않음, 두 사람의 네트워크 직거래, 토큰 재접속과 시작한 방 차단, NPC 채우기.
- `scripts/sim.ts`: NPC 4명으로 여러 판을 돌려 거래 수와 승률을 봅니다.

### NPC끼리 20판 돌린 결과

| 지표 | 값 |
|---|---|
| 한 판당 직거래 성사 | 약 13건 |
| 한 판당 제안 | 약 130건 (수락률 9%, 역제안 약 52건) |
| 경매 유찰 | 한 판에 1건 미만 |
| 승률 | 사기꾼 60%, 급처형 30%, 고집형 10% |

사기꾼 NPC가 많이 이기는 건 다른 NPC들이 "상태 좋아요"를 너무 쉽게 믿기 때문입니다. 사람끼리 하면 의심과 감정이 늘어 줄어들 것으로 보지만, 사람 테스트에서 사기가 계속 너무 강하면 감정 비용을 낮추거나 위반 공개를 강화합니다.

## 8. 재미 검증 질문

1. 다른 사람의 단상(가진 물건)을 보고 거래 전략을 바꾸는가?
2. 경매와 직거래 둘 다 의미 있는 선택인가?
3. 보증을 붙일지, 감정할지 고민하는 순간이 생기는가?
4. 사기를 당했을 때 억울함보다 "다음엔 안 속는다"가 먼저 드는가?
5. 한 판이 끝나고 "한 판 더"가 나오는가?
