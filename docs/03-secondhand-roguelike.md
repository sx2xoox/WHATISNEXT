# 직거래 (가제) — 중고거래 흥정 로그라이크

> 1인 개발 기준으로 추정했습니다. 수치는 모두 초안이며 프로토타입 결과로 수정합니다.

## 1. 한 줄 소개

중고거래 앱 채팅으로 싸게 사서 비싸게 되파는 흥정 로그라이크. 30일 안에 목표 금액(예: 전셋집 보증금)을 모아야 한다.

## 2. 핵심 판타지

- 눈썰미와 말빨만으로 돈을 불린다.
- 사기꾼의 수법을 간파하고 역으로 골탕 먹인다.
- 감정 흐름: 매물 발견의 설렘 → 흥정의 신경전 → 싸게 샀을 때와 비싸게 팔았을 때의 쾌감

## 3. 핵심 루프

| 단위 | 내용 |
|---|---|
| 30초 | 매물 확인 → 채팅으로 흥정 (말 카드 사용) |
| 1판 (30일, 20~30분) | 구매 → 상태 확인·수리 → 판매 글 등록 → 구매자와 흥정 → 목표 금액 달성 또는 실패 |
| 메타 (여러 판) | 감정 스킬, 단골 손님, 시작 특성 해금 |

## 4. 주요 메커닉

- **말 카드 덱**: 흥정을 자유 입력이 아니라 카드로 한다. 가격 제시, 칭찬, 하자 지적, 급한 척, 읽씹, 묶음 제안 같은 카드가 있다. 판마다 덱을 키워 나가는 덱빌딩 구조가 로그라이크 성장축이 된다.
- **상대 성격**: 급처형, 고집형, 사기꾼, 업자, 정 많은 할머니 등. 성격마다 잘 먹히는 카드가 다르다.
- **매너온도**: 평판 자원. 높으면 좋은 매물을 먼저 보고, 낮으면 거래를 거절당한다. 무리한 흥정과 평판 사이에서 고민이 생긴다.
- **사기 매물 단서**: 인터넷에서 퍼온 사진, 선입금 요구, 시세보다 지나치게 싼 가격. 간파하면 보상이 있다.
- **시세 변동 이벤트**: 신제품 출시로 구형이 폭락, 유행으로 특정 품목 폭등.
- **(선택) LLM 자유 채팅 모드**: 상대를 LLM으로 만들어 자유롭게 대화로 흥정한다. 기존 상점 게임과의 결정적 차별점이 될 수 있지만, API 비용과 결과 일관성 문제가 있어 확장 모드로 둔다.

## 5. 차별점과 유사 게임

| 유사 게임 | 공통점 | 차이점 |
|---|---|---|
| Recettear, Moonlighter | 사고팔아 돈 벌기 | 상점 운영이 아니라 **개인 간 채팅 흥정** |
| Pawnshop Simulator 류 | 물건 감정과 흥정 | 흥정이 단순 가격 슬라이더가 아니라 **카드 전략** |
| Slay the Spire, Balatro | 덱빌딩 로그라이크 | 전투가 아니라 **대화가 전투** |

**차별점 한 문장**: 메신저 화면 자체가 게임 화면이고, 흥정이 곧 카드 전투다.

## 6. 타깃과 플랫폼

- **타깃**: 모바일 캐주얼~미드코어. 국내 20~30대는 소재 자체에 공감한다. 해외는 eBay, Craigslist, Facebook Marketplace 문화로 현지화한다.
- **플랫폼**: 모바일 우선, PC(Steam) 동시 출시. 세로 화면 메신저 UI라 모바일과 잘 맞는다.

## 7. 수익 모델

- PC: 저가 유료 $9.99
- 모바일: 유료 앱, 또는 무료 + 광고 제거 결제
- 확장: 물품 팩, 시즌 이벤트(명절, 이사철)

## 8. 아트·사운드 방향과 제작 범위

- **아트**: 메신저 UI가 중심이고 물건은 픽셀 아이콘으로 표현한다. 물품 수가 많아서 PixelLab 대량 생성의 이점이 가장 큰 프로젝트다.
- **사운드**: 메시지 알림음, 입금 알림음 같은 익숙한 소리를 보상 피드백으로 쓴다.
- **출시 범위**: 물품 100~150종, 상대 성격 10종, 말 카드 40장, 랜덤 이벤트 50개

## 9. MVP에서 검증할 질문

1. 카드로 하는 흥정이 **실제 흥정처럼** 느껴지는가?
2. 사기꾼을 간파하는 게 재미있는가?
3. 10판을 해도 반복감이 없는가?

**MVP 범위**: 물품 20종, 상대 성격 3종, 말 카드 10장, 1판 = 10일

## 10. 일정 (1인 기준 추정)

| 단계 | 기간 |
|---|---|
| 프로토타입 | 1주 (셋 중 가장 짧음) |
| 버티컬 슬라이스 | 2개월 |
| Steam 데모 / 모바일 테스트 | 3~4개월 |
| 정식 출시 | 7~10개월 |

## 11. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 흥정이 반복되어 금방 질림 | 성격 조합, 랜덤 이벤트, 판마다 다른 목표 |
| 대사 분량이 많음 | 템플릿과 변수로 대사 생성, 성격별 말투 규칙 |
| 텍스트가 많아 현지화 비용이 큼 | 처음부터 텍스트를 외부 파일로 분리 |
| 실제 앱과 너무 비슷함 | 특정 서비스 UI·로고를 그대로 쓰지 않고 패러디 수준으로 |
| 비슷한 상점 게임과 구분되지 않음 | 카드 흥정과 사기 간파를 전면에 내세움 |

## 12. 중단 기준

- 3판 이후 "같은 카드만 반복해서 쓴다"는 반응이 나오면 카드와 성격 체계를 다시 설계한다.
- 그래도 반복감이 해결되지 않으면 접는다.
